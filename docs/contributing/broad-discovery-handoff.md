## Completed

The persistent Kalshi / Polymarket US workflow now unions keyword and pinned local ONNX embedding neighbors, then uses one bounded Jev pair assessment for event identity, outcome orientation, settlement clauses, and captured evidence references.
There is no mandatory Gemini extraction stage and no model-score admission cutoff.
Every valid current Jev same-event suggestion remains visible as Unverified; automatic settlement evidence independently determines Verified or Mismatch.
Native categories remain intact, with politics, economics, sports, other, and unknown browsing groups.
Actual binary US election instruments are admitted through the existing constraint checks.
Source capture rotates by category independently from quote allocation, which reserves exploratory capacity.

Discoveries exposes filtered coverage, processing states, source inventory exclusions, retrieval provenance, assessment blockers, original terms, and current/history inspection.
Opportunities separates Potential ordinary-outcome gaps from Qualified conditional estimates, with shareable filters, pagination, snapshot refresh, and explicit historical access.
Unknown financial inputs remain null and render as Unknown.
Changed inputs, quotes, fees, operator vetoes, and provider/source health retain their publication gates.
The mobile coverage summary was compacted after browser reproduction showed prices below the first fold.

Migration `b026_hybrid_retrieval` adds immutable model-versioned embeddings and durable retrieval state.
The backend image provisions its pinned model at build time and runs it offline as the application user.
The generated OpenAPI and TypeScript client include coverage, history, classification, inventory, and both result feeds.

## Limits and next action

Broad assessability does not mean every contract qualifies.
Authentic document applicability, exceptional-settlement interpretation, and provider evidence remain incomplete, and political same-event contracts can have different YES conditions.
No real profitable or automatically qualified pair is claimed by this milestone.
Embedding search uses bounded-memory exact search; large-catalog throughput and end-to-end latency have not been established.
No deployment, order placement, custody, or transfers were added.
An intermittent parallel browser quote-recovery timeout passed in isolation; the final fixture run uses one worker and isolated artifact directories.

Next action: run a sustained live Kalshi/US discovery coverage study across categories and use the recorded blocker distribution to prioritize authentic source-applicability and settlement-language extensions.
